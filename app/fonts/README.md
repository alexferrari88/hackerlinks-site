# Bundled fonts

These fonts are loaded with `next/font/local` so static builds do not fetch
Google Fonts CSS or depend on its intermittent extensionless URL responses
(https://github.com/vercel/next.js/issues/99114).

Source: https://github.com/google/fonts/tree/2fe1e8c6b137fb13041a7cfca6fdcd8a910ea4dc/ofl

- `bricolagegrotesque/BricolageGrotesque[opsz,wdth,wght].ttf`
- `publicsans/PublicSans[wght].ttf`
- `spacemono/SpaceMono-Regular.ttf`
- `spacemono/SpaceMono-Bold.ttf`

Each family's SIL Open Font License is included alongside the font files.
Keep these licenses when replacing or redistributing the fonts.
